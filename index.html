Las carpas del balneario, bajo control.

Sombrita es un sistema de consola en Python para registrar carpas, reservas y alquileres, sin superposiciones de fechas y con estadísticas de ocupación.

Qué hace

Tres menús que cubren la operación diaria de un balneario.

⛱️

Carpas

  • Registrar y listar carpas
  • Cambiar el número
  • Activar o inactivar (borrado lógico)
  • Consultar el estado por fechas
📅

Reservas y alquileres

  • Registrar con alta de cliente
  • Cancelar y cambiar el estado
  • Listar por fecha o por carpa
  • Buscar por cliente y ver las del día
📊

Estadísticas

  • Porcentaje de ocupación en un rango
  • Carpas libres en un rango
  • Cliente con más reservas

Una reserva está reservada (señada o sin pagar); un alquiler está alquilada (pagado). La gestión de cobros queda fuera del alcance.

Modelo de datos

Diccionarios, listas, tuplas y conjuntos, guardados en un único archivo datos/sombrita.json.

Estructuras

# Número de carpa -> activa
carpas: dict[int, bool] = {1: True, 10: False}

# DNI -> datos del cliente
clientes: dict[int, dict] = {
    30111222: {"nombre": "Juan Pérez",
               "telefono": "11-5555-1111"},
}

# Una carpa puede tener varias reservas
reservas: list[dict] = [
    {"carpa": 1, "dni": 30111222,
     "desde": "01/01/2027", "hasta": "15/01/2027",
     "estado": "alquilada"},
]

ESTADOS_RESERVA: tuple[str, str] = ("reservada", "alquilada")

Decisiones de diseño

  • Fechas como texto dd/mm/aaaa, convertidas a datetime para validar y comparar.
  • set para carpas ocupadas y DNI distintos.
  • Ordenamiento con quicksort recursivo.
  • Si el JSON está dañado, se guarda una copia .corrupto y se usan datos de ejemplo.

Convenciones

  • Funciones con prefijo _, salvo main() y los tests.
  • Docstring con Contrato, Precondiciones y Postcondiciones.
  • Type hints en todo el programa.
  • Sin clases ni variables globales.

Arquitectura

Las dependencias entre módulos van en un solo sentido, y la lógica está separada de la entrada y salida.

main.py
↓
menu_carpas
menu_reservas
menu_estadisticas
↓
persistencia
↓
comunes

menu_estadisticas usa directamente comunes; main.py también usa persistencia y comunes.

Flujo de una operación

  1. main() carga carpas, clientes y reservas, y los pasa por parámetro al menú elegido.
  2. El menú lee los datos del usuario y llama a una función de lógica, que no usa input() ni print().
  3. El menú muestra el resultado y, si hubo cambios, guarda el archivo.
  4. Al salir o con Ctrl+C, main() guarda los datos y termina.

Reglas de negocio

  • Número de carpa y DNI mayores a 0 y únicos.
  • Las carpas no se eliminan: se inactivan.
  • Una carpa con reservas no se puede inactivar.
  • Dos reservas de una carpa no pueden compartir ningún día.
  • Una reserva requiere carpa activa, cliente existente y desde ≤ hasta.
  • Una reserva se identifica por carpa, DNI y fecha de inicio.

Probarlo

Requiere Python 3.10 o superior. Los comandos se ejecutan desde la raíz del repositorio.

terminal
$ git clone https://github.com/gonzalezmkarend/ProyectoSombrita-TPO
$ cd ProyectoSombrita-TPO
$ python -m pip install -r requirements.txt
$ python main.py          # la primera vez crea datos/sombrita.json
$ python -m pytest        # corre las pruebas
